# Personal Portfolio Site

A modern, responsive personal portfolio website for Akhil Shelly, showcasing professional experience, skills, and contact information.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Dark Mode**: Toggle between light and dark themes with persistent user preference
- **Modern UI**: Clean, minimalist design built with Inter font and Font Awesome icons
- **SEO Optimized**: Includes Open Graph meta tags for social media sharing
- **Accessibility**: Keyboard navigation support for dark mode toggle with ARIA labels

## Tech Stack

- **HTML5**: Semantic markup
- **CSS3**: Custom properties (CSS variables) for theming
- **JavaScript**: Vanilla JS for dark mode toggle and localStorage
- **Fonts**: [Google Fonts - Inter](https://fonts.googleapis.com/css2?family=Inter:wght@300;400;600)
- **Icons**: [Font Awesome 5.4.2](https://fontawesome.com/)

## Setup

1. Clone or download this repository
2. Open `index.html` in a web browser
3. The site is ready to use—no build process required

## Customization

### Update Personal Information
Edit [index.html](index.html) to update:
- Name and title
- About section content
- Skills list
- Social media links
- Resume link

### Modify Styling
Edit [css/styles.css](css/styles.css) to customize:
- Color scheme (update CSS custom properties in `:root`)
- Font sizes and spacing
- Dark mode colors

## Deployment

This site is configured for GitHub Pages with a custom domain (`akhilshelly.com` via [CNAME](CNAME)).

To deploy:
1. Push to a GitHub repository
2. Enable GitHub Pages in repository settings
3. Point custom domain to GitHub's nameservers
